# meme-paper-bot

**Μόνο εικονικά trades (paper).** Διαβάζει live δεδομένα για νέα meme coins στο Solana, «αγοράζει» και «πουλάει» με κανόνες και καταγράφει τι θα είχε γίνει, με ρεαλιστικά κόστη. Κανένα πορτοφόλι, κανένα πραγματικό χρήμα.

Η σελίδα αυτή ενημερώνεται αυτόματα μόλις ολοκληρωθεί ο πρώτος γύρος του bot.
