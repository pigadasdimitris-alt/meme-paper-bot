# meme-paper-bot

**Μόνο εικονικά trades (paper).** Διαβάζει live δεδομένα για νέα meme coins στο Solana, «αγοράζει» και «πουλάει» με κανόνες και καταγράφει τι θα είχε γίνει — με ρεαλιστικά κόστη (2.5% slippage ανά πλευρά + $0.03 fee ανά συναλλαγή). Κανένα πορτοφόλι, κανένα πραγματικό χρήμα.

Dashboard: https://pigadasdimitris-alt.github.io/meme-paper-bot/
